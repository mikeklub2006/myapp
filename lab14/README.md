# Лабораторная работа № 14

Работа с файловой системой средствами Node.js.
Клубович Михаил, группа 401, вариант 8.

## Запуск

```bash
node task1.js
node task2.js
node task3.js [путь_к_директории]
node task4.js
node task5.js
```

## Задания

| Файл | Задание | Что делает |
|------|---------|------------|
| task1.js | Создание и чтение файлов | Создает `student_8.txt`, дописывает количество записей, выводит содержимое |
| task2.js | Работа с каталогами | Создает структуру `project_8`, выводит дерево, перемещает, переименовывает и удаляет папки |
| task3.js | Поиск и фильтрация | Рекурсивный анализ директории, статистика, отчет `report_8.json` |
| task4.js | Потоковая обработка | Генерация `data_8.txt` (100 000 строк), обработка потоком, отчет `processed_8.txt` |
| task5.js | Копирование и синхронизация | `source_8` → `backup_8`, сравнение каталогов, отчет `sync_report_8.txt` |

## Условия варианта 8

- Задание 2: вариант четный, в каждой папке дополнительно создается `README.md` с текущей датой
- Задание 3: папки `node_modules` и `.git` в статистику не включаются
- Задание 4: дополнительно выводятся 10 самых часто встречающихся чисел
- Задание 5: для файлов больше 500 КБ считаются контрольные суммы MD5

Требования: Node.js 16+, используются только `fs.promises`, `path` и потоки.
